# Software sob Demanda com IA

> **De usuário de IA → gestor de agentes.**
> Linha de formação INEMA sobre como trabalhar quando software, agentes e automações passam a ser criados sob demanda.

Pare de apenas usar ferramentas. Aprenda a mandar a IA **criar, operar e integrar** as ferramentas que você precisa.

| ANTES | AGORA |
|---|---|
| Problema → procurar software → comprar → aprender → configurar → operar | Problema → descrever resultado → IA pesquisa → cria/opera software → testa → entrega |

- **[PROPOSTA.md](PROPOSTA.md)** — a proposta completa: tese, 8 blocos, trilha de 6 níveis, catálogo de 10 cursos, 20 projetos, desafio 30 dias, plano de execução e decisões em aberto.

- **[conteudo/catalogo-astra-71.md](conteudo/catalogo-astra-71.md)** — os 71 exemplos do vídeo com criador, link para abrir e fonte (índice de AI Samson).
